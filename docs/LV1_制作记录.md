## 画风锁定

参考 v2 截图与 v1《V3角色与画风锁定》：

1. 暖纸底（#F6F1E7），低饱和米棕 / 灰蓝 / 暖灰，不用高饱和色块。
2. 细线（棕偏黑 #3A3633），轻薄水彩填色，克制阴影。
3. 可爱比例：脸小、眼大、下巴圆、腮红轻。
4. 每页只在留白处排字，气泡不压脸、不压手、不压关键道具。
5. 暖白椭圆气泡 + 同一闭合轮廓的尾巴（无根部内线）；说话者不在画面内时**不画尾巴**。
6. 旁白/画外转述用矩形框；正文 34–44px，旁白 24–50px。

## rev.3：标题与"她怎么认出他"的修订

**改了什么**

1. **副标题全换**。原「她拒绝的理由，比你画的还精彩」是在替读者解释笑点，读起来像广告语，很尬。改为「**我画的女生，从来不看我**」——作者本人口吻，不剧透，两层意思（分镜里她们看别人；现实里她们不看他）。
2. **系列名保留**《被拒绝的 NTR 老师》。它一句话交代前提，"老师"是"作者老师"的用法。
3. **匿名问题补上设定**：他是笔名「夜画」，四年没露过脸。她从未见过他的脸，**认的是线**——连载画风稳定到能被认出来。
4. **P4 原画重画**：桌子中间摊开分镜稿，她低头看一眼再抬眼。台词由「啊……你是那个画漫画的老师？」改成「这个分镜……是你画的吧？」。相认从"认脸"变成"认作品"，也让 P6–P7 她批评作品时更有立场。
5. **P1 加第三块旁白**「读者认不出我，他们只认得这条线。」——为 P4 埋伏笔。
6. **P5 左上旁白改词**「她说，她关注我很久了。每一话都看。」承接 P4 的相认。

**为什么这样更好**

- 匿名作者被认出来，靠脸是假的，靠"画风"是真的——现实中同人/连载作者被认出几乎都发生在线下稿子或画风上。
- 她先认得作品、再认得人，两人之间始终隔着"作品"这层，P7 的批评才不像人身攻击，而像读者对作者说话。
- 标题不提 NTR 和拒绝，把笑点留给正文，读者翻页才有"哦——"的那一下。

## rev.4：年龄改 24 岁（B 站梗）

- P1 首句改为「**我二十四岁，是……画 NTR 的。**」，句式和省略号一起暗示「24 岁，是学生」（B 站经典池沼梗）。只改数字没用——要保留"是……"这个破折句式，懂的人一眼就笑。
- 角色年龄 25 → 24（`docs/LV1_剧本与分镜.md` 同步）。他说「画 NTR，四年」，20 岁开始画，24 岁正好对得上"四年"。
- P1 排版：原来三块旁白，改为两块（第二块两行），全部落在显示器上方的暗墙，不压边线。
