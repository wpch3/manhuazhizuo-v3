## 画风锁定

参考 v2 截图与 v1《V3角色与画风锁定》：

1. 暖纸底（#F6F1E7），低饱和米棕 / 灰蓝 / 暖灰，不用高饱和色块。
2. 细线（棕偏黑 #3A3633），轻薄水彩填色，克制阴影。
3. 可爱比例：脸小、眼大、下巴圆、腮红轻。
4. 每页只在留白处排字，气泡不压脸、不压手、不压关键道具。
5. 暖白椭圆气泡 + 同一闭合轮廓的尾巴（无根部内线）；说话者不在画面内时**不画尾巴**。
6. 旁白/画外转述用矩形框；正文 34–44px，旁白 24–50px。

## 角色设定（锁定，跨页不得变化）

**她**：20 岁，咖啡店常客，在画植物速写。短发黑 bob，左侧细麻花辫，芥末黄小发夹；琥珀棕眼、浅腮红、细眉。米白针织开衫 + 白色圆领衬衫 + 藏青百褶裙。温柔、清醒、有礼貌、不刻薄。

**他（"我"）**：25 岁，出租屋，旧显示器 + 数位板 + 堆叠漫画书。只出现手、肩膀、后脑和后段搭在桌上的手。

## 本轮解决的两个技术问题

1. **P10 原图自带一个空白矩形**（生成瑕疵）。不擦除——改为把它当作"画中画旁白格"，把孙辈的画外音放进去。空白块因此变成构图的一部分。
2. **P9 原画易产生乱码文字**（上一版易拉罐上有伪字符）。重新生成并要求"所有道具无任何文字"，已确认无字母。
