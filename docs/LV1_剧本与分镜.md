# LV1 剧本与分镜（定稿 v2，与 build_lv1.py 完全一致）

> 系列：**《被拒绝的 NTR 老师》**／单话标题：**《第 1 话：她拒绝的理由，比你画的还精彩》**
> 体裁：竖屏第一人称漫画，3:4（1440×1920），封面 + 10 页正文（共 11 页）
> 画风：v2 的暖纸色/细线/低饱和/可爱脸；排版：v1 的椭圆气泡与真实文字居中

## 一、核心设定

1. **第一人称**：镜头即「他」的眼睛。他基本不出脸，只出现手、肩膀、后脑和把手搭在桌上的那一下。
2. **他**：25 岁，画 NTR 黑白漫，靠"让读者生气"涨粉。他真正相信的是——**没有比「原本属于我的人被别人抢走」更动人的故事**。他爱的不是人，是"被抢走"这件事。
3. **女生不背锅**：她温柔、清醒、有礼貌，拒绝干净利落。刀刃只对准他。
4. **尺度**：全员成年，无露骨内容，"抢夺"只用台词与标题梗带过。
5. **每话一句最狠的台词**（本话在第 7 页）。

## 三、叙事逻辑自查

- **P8 完成反讽**：他笔下的"被抢走"需要一个前提——她先属于某个人。而这里根本没有人抢，她只是先有了自己的生活。
- **P9 是转折**：他不是被惩罚，而是自己写不下去了。"画不下去"比"没人爱"更狠，也更真实。
- **P10 是温柔**：四十年后他还在画，而且在画纯爱。读者笑完会心里软一下——这是全系列的地基。
- **P10 是第一人称唯一例外**：镜头客观地看见"未来的他"，距离本身就是惩罚。
